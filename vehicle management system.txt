Software Requirements Specification (SRS)
Vehicle Rental Management System
1. Introduction
1.1 Purpose
This document describes the Software Requirements Specification for the Vehicle Rental Management System (VRMS). 
The purpose of this system is to automate vehicle rental operations including vehicle booking, customer management,
payment handling, and rental tracking.
1.2 Scope
The Vehicle Rental Management System allows administrators and customers to manage rental activities digitally.
The system helps in vehicle listing, availability tracking, reservation management, billing, and reporting.
1.3 Definitions, Acronyms, and Abbreviations
VRMS – Vehicle Rental Management System
Admin – System Administrator
User – Customer using the rental service
1.4 Overview
This document describes the system perspective, system features, functional requirements, non‑functional requirements,
and external interface requirements.
2. Overall Description
2.1 Product Perspective
The system is a standalone web or desktop application that manages vehicle rental operations for a rental company.
2.2 Product Functions
Main functions of the system include:
- Vehicle registration and management
- Customer registration and management
- Vehicle booking and reservation
- Rental tracking
- Payment processing
- Report generation
2.3 User Classes and Characteristics
Administrator:
- Manages vehicles
- Manages users
- Approves rentals
- Generates reports
Customer:
- Registers in the system
- Searches vehicles
- Books vehicles
- Makes payments
2.4 Operating Environment
The system may run on:
- Windows OS
- Web browser (Chrome, Edge, Firefox)
- Database Server (MySQL / SQL Server)
2.5 Design Constraints
- Must support secure login
- Database must maintain integrity
- UI should be simple and user friendly
2.6 Assumptions and Dependencies
- Users have internet access (for web system)
- Database server is always available
3. System Features
3.1 User Registration
Customers can register by providing personal details such as name, phone number, email, and password.
3.2 Login System
Both admin and customers must log in using valid credentials.
3.3 Vehicle Management
Admin can:
- Add new vehicles
- Edit vehicle information
- Delete vehicles
- Mark vehicles as available or unavailable
3.4 Vehicle Search
Customers can search vehicles by:
- Vehicle type
- Price
- Availability
- Brand
3.5 Vehicle Booking
Customers can select available vehicles and book them for a specific period.
3.6 Payment Processing
Customers pay rental fees based on vehicle price and rental duration.
3.7 Rental Management
Admin can track:
- Active rentals
- Completed rentals
- Overdue rentals
3.8 Reports
Admin can generate reports including:
- Vehicle usage report
- Rental history
- Payment report
4. External Interface Requirements
4.1 User Interface
The system provides a simple GUI including:
- Login page
- Dashboard
- Vehicle list page
- Booking page
- Payment page
- Admin control panel
4.2 Hardware Interface
The system runs on standard computers or servers.
4.3 Software Interface
- Database system (MySQL or SQL Server)
- Web server (if web application)
4.4 Communication Interface
The system communicates with the database through SQL queries.
5. Functional Requirements
FR1: The system shall allow users to register accounts.
FR2: The system shall allow users to log in securely.
FR3: The admin shall be able to add, edit, and delete vehicles.
FR4: Customers shall be able to search for vehicles.
FR5: Customers shall be able to book vehicles.
FR6: The system shall calculate rental costs.
FR7: The system shall store rental records.
FR8: The admin shall be able to generate reports.
6. Non‑Functional Requirements
Performance:
The system should process user requests within 3 seconds.
Security:
User passwords must be encrypted.
Usability:
The interface must be simple and easy to understand.
Reliability:
The system must maintain accurate rental and payment records.
Availability:
The system should be available 24/7.
7. Future Enhancements
- Mobile application support
- Online payment gateway integration
- GPS tracking for rented vehicles
- Email/SMS booking notifications
